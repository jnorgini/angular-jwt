Sistema para controle e gerenciamento de clientes.

O login autenticado com JWT (Json Web Token) garante a segurança e praticidade.

A implementação focada na eficiência e na facilidade de uso proporciona uma experiência intuitiva.

Tecnologias utilizadas:

Back-End: Java, Spring Boot, JPA, Spring Web, Lombok, ModelMapper, Spring Security, JWT e Validation. Database MySQL (development) e PostgreSQL com host ElephantSQL (prod).

Front-End: TypeScript, Angular, TailwindCSS, Fontsawesome (icons), ngx-mask e Toastr.
